# Financial Model: SoloFi (Freelance Neobank)

## 📊 Unit Economics

### Customer Acquisition Cost (CAC)

Consumer FinTech is hyper-competitive. We must rely on organic growth loops (referrals) to survive against massive incumbents like Monzo/Revolut.
| Channel | Cost | Conversion Rate | CAC |
|---------|------|----------------|-----|
| Meta / TikTok Ads | £20/click | 3% install rate | £666 (Unsustainable) |
| Referral Program ("Give £50, Get £50")| £100/referral | 100% (Guaranteed) | £100 |
| Freelance Communities (Discord/Reddit)| Free | High | £15 |
| **Blended Target** | | | **£85** |

### Lifetime Value (LTV)

| Metric                          | Value                                                                    |
| ------------------------------- | ------------------------------------------------------------------------ |
| Average Revenue Per User (ARPU) | £10/mo (SaaS Pro Tier) + £15/mo (Interchange) + £5/mo (Tax Sub) = £30/mo |
| Gross Margin                    | 50% (BaaS APIs and Mastercard network fees eat half of ARPU)             |
| Churn Rate                      | 3% /month (Freelancers frequently return to full-time employment)        |
| Customer Lifetime               | 33 months                                                                |
| **LTV**                         | **£495**                                                                 |

### LTV:CAC Ratio

| Metric    | Target        | Status                                            |
| --------- | ------------- | ------------------------------------------------- |
| LTV       | £495          | -                                                 |
| CAC       | £85           | -                                                 |
| **Ratio** | 3.5:1 minimum | **5.8:1 (Very healthy for Consumer/SMB FinTech)** |
