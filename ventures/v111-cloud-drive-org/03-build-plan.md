# Build Plan: CloudSync Infrastructure

## 🛠️ Tech Stack

- **Backend**: Node.js + Python for indexing.
- **Database**: Elasticsearch for search.
- **Integrations**: Official APIs for GDrive, Dropbox, OneDrive.
- **Frontend**: React.

## 📋 MVP Core Requirements

1.  **OAuth Connections**: Connect to all three platforms.
2.  **Metadata Indexing**: Index file names, types, dates.
3.  **Search Engine**: Unified search results.
4.  **Simple UI**: Results with source indicators.
