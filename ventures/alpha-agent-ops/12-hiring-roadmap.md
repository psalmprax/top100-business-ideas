## 👥 Role Specifications

### Role: Principal Systems Engineer (Rust/Go)
**Department**: Engineering
**Location**: Remote-first

**Responsibilities**:
- Own the high-throughput proxy data plane.
- Implement streaming proxy support (Server-Sent Events) for ChatGPT-style streaming responses.
- Optimize the Redis-based semantic cache for sub-10ms lookups.

**Requirements**:
- 5+ years building distributed systems, API gateways, or edge proxies.
- Deep expertise in Rust (Tokio) or Go.
- Experience with Kubernetes and Docker deployments.
