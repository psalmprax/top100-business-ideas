# Build Plan: CryptaVault Infrastructure

## 🛠️ Tech Stack

- **Desktop**: Electron + React (cross-platform).
- **AI**: Llama.cpp for local inference.
- **Database**: SQLite (local) + custom sync protocol.
- **Encryption**: Web Crypto API.

## 📋 MVP Core Requirements

1.  **Local Notes**: Markdown editor with local storage.
2.  **Local AI**: Llama-based semantic search.
3.  **Encryption**: AES-256 file encryption.
4.  **Export**: Standard markdown export.

## 📦 Key Deliverables

- [ ] Desktop App (Mac/Win/Linux).
- [ ] Mobile Apps (iOS/Android).
- [ ] Local AI Search.
- [ ] E2E Sync (optional).
