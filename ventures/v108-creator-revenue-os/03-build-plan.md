# Build Plan: CreatorCash Infrastructure

## 🛠️ Tech Stack
- **Backend**: Node.js (Express) + Python for data processing.
- **Database**: PostgreSQL for financial data.
- **Integrations**: Official APIs from YouTube, Patreon, TikTok.
- **Frontend**: React + Tailwind.

## 📋 MVP Core Requirements
1.  **Platform Connections**: OAuth for major platforms.
2.  **Data Aggregation**: Unified earnings API.
3.  **Dashboard**: Visual earnings overview.
4.  **Alerts**: Payment notifications.
