# Financial Model: LivenessLink

## 📊 Unit Economics

### Customer Acquisition Cost (CAC)

Treasury professionals are notoriously difficult to reach. Selling cyber-security software to a CFO requires a massive "Trust" premium.
| Channel | Cost | Conversion Rate | CAC |
|---------|------|----------------|-----|
| Direct Outbound (BDRs) | £500/lead | 2% | £25,000 |
| Exclusive Private Dinners | £5,000/dinner | 10% | £5,000 (Very high conversion) |
| Channel Partnerships (Kyriba, SAP) | £0/referral | 20% | £0 (30% Rev share later) |
| **Blended Target** | | | **£12,000** |

### Lifetime Value (LTV)

| Metric                          | Value                                              |
| ------------------------------- | -------------------------------------------------- |
| Average Revenue Per User (ARPU) | £4,000/month (Enterprise avg)                      |
| Gross Margin                    | 80% (Biometric/Identity DB hosting is expensive)   |
| Churn Rate                      | 0.5% /month (Near-zero churn once embedded in ERP) |
| Customer Lifetime               | 200 months                                         |
| **LTV**                         | **£640,000**                                       |

### LTV:CAC Ratio

| Metric    | Target      | Status                                      |
| --------- | ----------- | ------------------------------------------- |
| LTV       | £640,000    | -                                           |
| CAC       | £12,000     | -                                           |
| **Ratio** | 3:1 minimum | **53.3:1 (Exceptional Enterprise Metrics)** |
