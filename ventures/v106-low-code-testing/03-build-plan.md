# Build Plan: NoCodeQA Infrastructure

## 🛠️ Tech Stack

- **Backend**: Node.js (Express).
- **Testing**: Puppeteer for browser automation.
- **Database**: PostgreSQL for test configs.
- **Frontend**: React + Tailwind.

## 📋 MVP Core Requirements

1.  **Test Recorder**: Chrome extension to record actions.
2.  **Test Runner**: Execute tests against workflows.
3.  **Results Dashboard**: Pass/fail visualization.
4.  **Webhook Triggers**: Run tests on workflow updates.

## 📦 Key Deliverables

- [ ] Test Recorder Extension.
- [ ] Web Dashboard.
- [ ] Zapier/Make Integration.
- [ ] Slack Notifications.
