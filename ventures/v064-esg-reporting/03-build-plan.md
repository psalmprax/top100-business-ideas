# Build Plan: SustainBase Governance Platform

## 🛠️ Tech Stack
- **Frontend**: Next.js (Admin dashboard style).
- **Backend**: Go (for high-volume data ingestion and processing).
- **Audit Trail**: PostgreSQL with a Ledger architecture (immutability).
- **AI/ML**: Natural Language Processing (NLP) to scan company policy docs and map them to ESRS requirements.

## 📋 MVP Core Requirements
1.  **Materiality Wizard**: A logical flow that allows a Sustainability Manager to rank "Impact" and "Financial Risk" per CSRD standards.
2.  **Document Vault**: Encrypted storage for "Evidence Docs" linked to ESG data points.
3.  **PDF/XBRL Exporter**: The final report must be in the EU-mandated machine-readable format.

## 📦 Key Deliverables
- [ ] Double Materiality Assessment Tool.
- [ ] ESRS Gap Analysis Dashboard.
- [ ] Supplier Data Collaboration Portal.
