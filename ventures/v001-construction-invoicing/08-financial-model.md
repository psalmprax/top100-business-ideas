# Financial Model: Structura (Construction Invoicing)

## 📊 Unit Economics

### Customer Acquisition Cost (CAC)
The construction industry is archaic. Digital marketing works poorly. Trade shows and direct outbound are king.
| Channel | Cost | Conversion Rate | CAC |
|---------|------|----------------|-----|
| Trade Shows / Expos | £10,000/event | 20 closes | £500 |
| Cold Calling (BDRs) | £80/lead | 10% | £800 |
| Software Integrators (Procore) | £0/referral | 20% | £0 (App store tax) |
| **Blended Target** | | | **£650** |

### Lifetime Value (LTV)
| Metric | Value |
|--------|-------|
| Average Revenue Per User (ARPU) | £350/month (Base SaaS) + £500/mo (FinTech fees) = £850/mo |
| Gross Margin | 75% (FinTech payment rails lower blended margin) |
| Churn Rate | 2% /month (Construction firms fail during downturns) |
| Customer Lifetime | 50 months |
| **LTV** | **£31,875** |

### LTV:CAC Ratio
| Metric | Target | Status |
|--------|--------|--------|
| LTV | £31,875 | - |
| CAC | £650 | - |
| **Ratio** | 3:1 minimum | **49:1 (Highly Capital Efficient)** |
