# Extended Use Cases: InboxZen (Email Inbox Control)

## Core Use Cases (1-3)
### Use Case 1: The "High-Priority" Filter
Uses LLMs to categorize emails by "Direct Action Required" vs. "For Info" based on your actual job role.
### Use Case 2: One-Click Newsletter Unsubscribe
Aggregated view of all newsletters with a single "Kill All" button that actually works.
### Use Case 3: Automated Follow-up Reminders
Triggers a nudge if you haven't replied to a critical client email within 24 hours.

---

## Extended Use Cases (4-10)

### Use Case 4: Rule-Based "Inbox Cleanup" (Self-Service)
**Scenario**: User has 10,000 unread emails and wants a fresh start.
**Solution**: "Safe-Archive" wizard that identifies non-essential emails (newsletters, old notifications) and archives them in bulk while preserving marked "Gems."

### Use Case 5: CRM-Action Sync (Integration)
**Scenario**: Identifying if an email is from a "High-Value" lead in HubSpot.
**Solution**: Cross-references sender data with CRM; automatically moves leads to the "VIP" tab and provides context (e.g., "Last deal size: £5k") inside the email view.

### Use Case 6: Response Time Analytics
**Scenario**: Tracking how long it takes the user to reply to clients.
**Solution**: Monthly "Efficiency Report" showing average reply time, number of ignored threads, and suggestions for "Template-Aided" quick replies.

### Use Case 7: Executive Assistant Access (SLA)
**Scenario**: EA needs to manage the Inbox without having the user's primary credentials.
**Solution**: Secure "Mirror Access" with restricted permissions (e.g., can draft but not send) and enterprise-grade support.

### Use Case 8: Mobile "Triage" Mode
**Scenario**: Sorting the inbox during a commute.
**Solution**: Swipe-heavy mobile interface designed specifically for rapid categorization (Keep, Archive, Delegate) rather than typing deep replies.

### Use Case 9: Phishing & Malicious Link Detection (Security)
**Scenario**: Receiving a sophisticated spoofed email.
**Solution**: "Active-Scan" layer that check-sums link destinations and warns the user before they click a link that deviates from the sender's known domain.

### Use Case 10: Legal Hold & Search (Compliance)
**Scenario**: Internal investigation requires searching for specific keywords across deleted items.
**Solution**: Compliance-grade "Deep-Search" that can index archived or deleted mailboxes for regulatory audit purposes.
