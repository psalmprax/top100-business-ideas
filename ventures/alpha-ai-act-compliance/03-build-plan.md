# Build Plan: ReguLens Governance Suite

## 🛠️ Tech Stack
- **Frontend**: Next.js (Safe, compliant-looking UI).
- **Backend**: Node.js / TypeScript.
- **AI Engine**: Specialized LLM fine-tuned on the **EU AI Act official text** and legal interpretations.
- **Security**: SOC2/GDPR redundant storage; encryption at rest (essential for sensitive training data audits).

## 📋 MVP Core Requirements
1.  **Classification Wizard**: User answers 12 questions -> System provides legal certainty on "High-Risk" status.
2.  **Annex IV Template Engine**: PDF/JSON generator for the mandatory technical file.
3.  **Bias Auditor**: A small tool that checks CSV/Parquet training metadata for demographic imbalance.

- [ ] Compliance Dashboard.
