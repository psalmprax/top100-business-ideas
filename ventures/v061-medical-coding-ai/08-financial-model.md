# Financial Model: MediParse (Medical Coding AI)

## 📊 Unit Economics

### Customer Acquisition Cost (CAC)
Selling to Hospital Chief Revenue Officers (CROs) is brutal. The sales cycle is 9-12 months.
| Channel | Cost | Conversion Rate | CAC |
|---------|------|----------------|-----|
| Healthcare Trade Shows (HIMSS) | £20,000/event | 2 closes | £10,000 |
| EHR Partnerships (Epic/Cerner) | £0/referral | 20% | £0 (Revenue share 25%) |
| Direct Enterprise Outbound | £2,000/lead | 5% | £40,000 |
| **Blended Target** | | | **£25,000** |

### Lifetime Value (LTV)
| Metric | Value |
|--------|-------|
| Average Revenue Per User (ARPU) | £15,000/month (Enterprise Hospital System) |
| Gross Margin | 85% (Replacing human offshore labor with LLM compute) |
| Churn Rate | 0.25% /month (Once integrated into Epic, it is never removed) |
| Customer Lifetime | 400 months |
| **LTV** | **£5,100,000** |

### LTV:CAC Ratio
| Metric | Target | Status |
|--------|--------|--------|
| LTV | £5,100,000 | - |
| CAC | £25,000 | - |
| **Ratio** | 5:1 minimum | **204:1 (Astonishingly lucrative, but gated by 12-month sales cycles)** |
