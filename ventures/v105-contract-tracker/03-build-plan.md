# Build Plan: ObligationTrack Infrastructure

## 🛠️ Tech Stack

- **Backend**: Python (FastAPI) + LangChain for extraction.
- **Database**: PostgreSQL for contract storage.
- **OCR**: AWS Textract for PDF parsing.
- **Frontend**: React + Tailwind.

## 📋 MVP Core Requirements

1.  **PDF Upload**: Drag-and-drop contract ingestion.
2.  **Date Extraction**: Find renewal, termination dates.
3.  **Calendar View**: Visual timeline of obligations.
4.  **Alert System**: Email notifications.

## 📦 Key Deliverables

- [ ] Web Dashboard.
- [ ] PDF Parser.
- [ ] Calendar Integration (Google, Outlook).
- [ ] Slack Alerts.
