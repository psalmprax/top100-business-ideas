# Build Plan: GreenMetrics Infrastructure

## 🛠️ Tech Stack

- **Backend**: Python (FastAPI) for analysis engine.
- **Scraper**: Playwright for rendering JavaScript-heavy sites.
- **Database**: PostgreSQL for scan history.
- **Analysis**: Custom carbon calculation algorithms.

## 📋 MVP Core Requirements

1.  **URL Analyzer**: Fetch and analyze page components.
2.  **Carbon Calculator**: CO2 per page view algorithm.
3.  **Simple Report**: Basic PDF/HTML output.
4.  **Dashboard**: Web UI for viewing results.

- [ ] GreenMetrics Web Tool.
- [ ] Chrome Extension.
- [ ] API for developers.
- [ ] PDF Report Generator.
