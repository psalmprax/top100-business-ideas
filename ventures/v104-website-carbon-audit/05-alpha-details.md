# Alpha Venture Details: GreenMetrics

## Market Context

- **TAM**: $2.1B (ESG Tech) by 2028.
- **Growth driver**: EU CSRD requires digital carbon reporting.
- **No dominant player**: Fragmented tools, no market leader.

## Competitive Landscape

| Competitor     | Description      | Weakness             |
| -------------- | ---------------- | -------------------- |
| Website Carbon | Basic calculator | Limited features     |
| Ecoping        | Consumer-focused | Not enterprise-ready |
| Carbon Trust   | Consulting       | No SaaS product      |

## GTM Strategy

1. Free website audits as lead magnet.
2. Partner with web agencies.
3. ESG software integrations.

## Defensibility

- Proprietary carbon algorithms.
- Hosting provider verification.
- CSRD compliance reporting.
