# Extended Use Cases Template

## Overview

This document provides a template for creating comprehensive use case documentation for each venture. Each venture should have 10 use cases covering the full customer journey from discovery to enterprise features.

## Structure

### Core Use Cases (1-3)
These are the **competitive override** use cases that differentiate the product from competitors.

| # | Use Case | Description |
|---|---------|-------------|
| 01 | Primary Value #1 | Core differentiation point |
| 02 | Primary Value #2 | Key competitive advantage |
| 03 | Primary Value #3 | Additional value driver |

### Extended Use Cases (4-10)
These cover the full customer journey and enterprise requirements.

| # | Use Case Type | Example |
|---|---------------|---------|
| 04 | Self-Service/DIY | Onboarding without help |
| 05 | Integration | API/connector/GraphQL scenarios |
| 06 | Analytics | Reporting/dashboard |
| 07 | Support | Enterprise SLA |
| 08 | Mobile | Mobile-first workflows |
| 09 | Security | Enterprise SSO |
| 10 | Compliance | Audit trail |

---

## Customer Journey Mapping

| Stage | Use Cases | Focus |
|-------|-----------|-------|
| **Discovery** | 1-3 | Core value proposition |
| **Onboarding** | 4-5 | Setup and configuration |
| **Daily Use** | 6-7 | Operations and monitoring |
| **Scale** | 8-9 | Growth and expansion |
| **Enterprise** | 10 | Advanced features |
