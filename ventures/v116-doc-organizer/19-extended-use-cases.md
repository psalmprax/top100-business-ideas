# Extended Use Cases: AutoDoc (Doc Organizer)

## Core Use Cases (1-3)

### Use Case 1: Automated Receipt/Invoice Extraction

Automatically pulls key data (Vendor, Amount, Date, Tax) from PDFs and images and categorizes them for accounting.

### Use Case 2: Semantic Document Clustering

Groups related documents (e.g., "All files related to the house renovation") using AI, regardless of their filenames or original folders.

### Use Case 3: Document Summary Gallery

Generates 1-sentence summaries and key-word tags for every document so you can browse a "Visual Feed" of your files instead of a list.

---

## Extended Use Cases (4-10)

### Use Case 4: Automatic Folder Structuring (Self-Service)

**Scenario**: User has a "Misc" folder with 500 unorganized files.
**Solution**: "Tidy-Up" agent that suggests a new folder hierarchy (e.g., By Client -> By Project -> By Year) and moves files after user confirmation.

### Use Case 5: Accounting/ERP Sync (Integration)

**Scenario**: Matching extracted invoice data with QuickBooks/Xero transactions.
**Solution**: Direct API connector that pushes PDF receipts and their metadata into the accounting ledger for automated reconciliation.

### Use Case 6: Tax-Season "Expense Report"

**Scenario**: Accountant asks for "All travel receipts from 2025."
**Solution**: One-click generation of a "Proof-of-Expense" ZIP file containing the data export and all associated PDF evidence.

### Use Case 7: Managed Document Migration (SLA)

**Scenario**: Transitioning a legacy paper archive (digitized) into a searchable cloud system.
**Solution**: Premium "Migration Audit" where AutoDoc verifies the accuracy of OCR on every single page of a high-volume import.

### Use Case 8: Mobile "Snap & Sort"

**Scenario**: Getting a physical receipt at a restaurant.
**Solution**: Mobile camera interface with real-time OCR that categorizes the receipt and uploads it to the "Company Travel" folder before the user leaves the table.

### Use Case 9: Document Sensitivity Masking (Security)

**Scenario**: Sharing a contract but needing to hide the price or specific names.
**Solution**: AI-powered "Redaction Layer" that permanently blacks out PII or sensitive figures before generating a shareable link.

### Use Case 10: GDPR/CCPA Data Discovery (Compliance)

**Scenario**: A customer submits a "Right to be Forgotten" request.
**Solution**: Deep-scan across the entire document repository to find all occurrences of that user's name or email to ensure 100% compliance.
