# Build Plan: TaskFlow AI Infrastructure

## 🛠️ Tech Stack

- **Backend**: Python (FastAPI) + LangChain.
- **Speech**: Whisper for transcription.
- **NLP**: GPT-4 for task extraction.
- **Database**: PostgreSQL for tasks.

## 📋 MVP Core Requirements

1.  **Audio Upload**: Accept meeting recordings.
2.  **Transcription**: Convert audio to text.
3.  **Task Extraction**: Identify commitments.
4.  **Export**: Send to task managers.

## 📦 Key Deliverables

- [ ] Web Dashboard.
- [ ] Zoom/Google Meet Integration.
- [ ] Asana/Todoist Sync.
- [ ] Slack Integration.
