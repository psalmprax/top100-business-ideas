## 🎯 Feature Prioritization Framework

### RICE Scoring

| Factor         | Weight | Description                                                   |
| -------------- | ------ | ------------------------------------------------------------- |
| **R**each      | \_\_\_ | How many users affected?                                      |
| **I**mpact     | \_\_\_ | How much does it help? (3=massive, 2=high, 1=medium, 0.5=low) |
| **C**onfidence | \_\_\_ | How sure are we? (100%, 80%, 50%)                             |
| **E**ffort     | \_\_\_ | Person-weeks needed                                           |

**Score = (R × I × C) / E**
