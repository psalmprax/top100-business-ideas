# Build Plan: CostControl Infrastructure

## 🛠️ Tech Stack
- **Backend**: Python (Django) for complex business logic.
- **Database**: PostgreSQL for SaaS inventory + usage data.
- **Integrations**: OAuth for Google Workspace, Microsoft, Slack.
- **Browser**: Chrome Extension (React).

## 📋 MVP Core Requirements
1.  **Email Scanner**: Parse expense confirmation emails to detect SaaS purchases.
2.  **App Database**: Pre-populated database of 50,000 SaaS products with pricing.
3.  **Simple Dashboard**: List all detected apps with spend estimates.
4.  **Alert System**: Email notifications for new subscriptions.

## 📦 Key Deliverables
- [ ] CostControl Dashboard (Web).
- [ ] Browser Extension (Chrome).
- [ ] Slack Integration.
- [ ] Google Workspace OAuth connector.
