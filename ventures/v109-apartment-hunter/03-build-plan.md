# Build Plan: RentPulse Infrastructure

## 🛠️ Tech Stack

- **Backend**: Python (FastAPI) for scraping and automation.
- **Database**: PostgreSQL for listings and user data.
- **Scraping**: Playwright + custom scrapers for listing sites.
- **Frontend**: React + Tailwind.

## 📋 MVP Core Requirements

1.  **Listing Scraper**: Monitor Zillow, Rightmove, Apartments.com.
2.  **Alert System**: Push notifications for new listings.
3.  **Search UI**: Filter and save searches.
4.  **Favorites**: Save and organize listings.

- [ ] Web Dashboard.
- [ ] Mobile App (iOS/Android).
- [ ] Chrome Extension.
